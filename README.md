# 百炼英雄挂机脚本

基于 OpenCV 图像识别 + 鼠标模拟的微信小程序《百炼英雄》挂机脚本（Windows 版）。
仅供个人娱乐学习，请勿商用；挂机存在账号风险，请谨慎使用。

## 功能与模式

| 模式 | 说明 |
|---|---|
| 冰封禁区自动挂机打怪 | 冰冠堡垒 3 层-冰冠禁区，绕圈引怪打怪 |
| 自动收集木材 | 冰冠堡垒 1 层-王座大厅，自动打怪收木头 |
| 自动采矿 | 严寒地带-北风营地，自动采矿 |
| 冰封王座自动挂机打怪 | 冰冠堡垒 4 层-冰封王座 |
| 自动打BOSS刷金币 | 按配置路线传送、打 Boss、回城循环，路线可自定义 |

## 环境要求

- Windows + Python 3.13
- 依赖：`pyautogui`、`pynput`、`pillow`、`opencv-python`、`numpy`（见 `requirements.txt`）
- 项目自带 `.venv` 虚拟环境，可直接使用

      是否全自动（默认是）

## 校准说明（首次使用必做）

脚本的所有点击都基于屏幕坐标，而坐标因**电脑、窗口尺寸、游戏界面**而异，所以每个使用者都要在**自己的电脑**上做一次校准。校准数据保存在 `config/calibration.json`（已加入 .gitignore，不会上传，也不会互相覆盖）。

**校准完成后，点位就只由这份校准数据决定。** 界面上填的宽高只是记录：在挂机界面改、还是在校准工具里改，两边会自动同步成同一个值，而且都不影响点击位置 —— 量窗口尺寸时含不含上面那条白色标题栏都无所谓，前后量法一致就行。只有把窗口**真的拉大或缩小**之后坐标才会失效，需要重新校准。

校准步骤：

1. 打开游戏，把小程序窗口调整到你要长期使用的尺寸（建议约 7.5 × 13.5 cm），放到任意位置（建议固定一个位置）
2. 双击 `校准工具.bat`，窗口顶部会实时显示鼠标坐标
3. 按列表逐项把鼠标悬停到游戏里对应的元素上，按 **F2** 或点“捕获鼠标位置到当前项”：
   - **角色中心**：游戏里角色站的位置（聚焦 / 拖拽起点）
   - **传送按钮**：打开传送菜单的按钮
   - **传送按钮(首次)**：刚打开小程序时的传送按钮位置（仅首次打开时使用）
   - **回城按钮**：返回城镇的按钮
   - **回城确认框**：回城时弹出的确认按钮
   - **地图列表第1项 / 第2项**：传送菜单里第一张、第二张地图（必填）
   - **层数列表第1项 / 第2项**：传送菜单里第一层、第二层（必填）
4. 点“保存校准”（会自动记录窗口位置，之后窗口移动也能准确定位）

### 地图 / 层数逐项校准

传送菜单里每一项的位置 = 第1项坐标 + 间距 × (序号 − 1)，所以间距准不准，直接决定后面的项会不会点偏。

- **必填**：地图列表、层数列表各只要填第 1、2 项。填完这两项，工具会**自动算出间距**（第2项 y − 第1项 y），后面的项由脚本按间距推算 —— 不需要你填任何数字。
- **可选**：第 3 项往后。顺手多捕获几项，工具会取相邻项的平均间距，结果更准；某张地图或某一层单独点偏，就单独捕获那一项，脚本优先用实测坐标。
- 工具里那栏「间距(自动)」是**只读**的，值由实测坐标算出来，不用也不能手填。

需要额外校准的情况：

- **地图 4、5 及更后面**：在工具里选中「地图列表第4项」……把鼠标悬停到那张地图上按 F2 捕获
- **第 3 层及以上的层数**：同样选中「层数列表第3项」……逐项捕获
- 工具会把实测坐标写进 `calibration.json` 的 `map_positions` / `level_positions`，并保证「第1项坐标」和逐项坐标是同一套值，不会再出现两套数字打架的情况

注意：**窗口真的改过大小后必须重新校准**；窗口位置可以随意移动（脚本自动跟随）。

## 图像识别的作用

脚本内置 OpenCV 图像识别，主要带来三方面体验优化：

- **传送更快更准**：点完传送后自动确认菜单打开（没开会自动重试），并检测传送是否完成（窗口画面稳定），不再固定傻等；加载快就快，加载慢也能等够
- **打 Boss 更智能**：Boss 打完、画面静止后自动回城，不用干等固定秒数；名字带 `xb` 的过图条目会自动跳过战斗判定
- **窗口自适应**：自动定位“百炼英雄”窗口，窗口放屏幕哪个位置都能准确定位，不再要求贴左上角

识别不可用（如模板缺失、截屏失败）时，脚本会自动回退到固定等待，不影响基本使用。

## 自动打BOSS刷金币：自定义路线

打 Boss 模式支持自定义传送路线，只需编辑 `config/boss_path.json`，无需改代码。
- `routes`：路线集合，界面下拉框可切换；每轮循环自动重新读取，改完无需重启
- 每个 Boss 条目：
  - `name`：名称（随意；名字含 `xb` 表示不打 Boss，只过图）
  - `map` / `level`：传送到第几张地图第几层（按传送菜单里的顺序）
  - `steps`：传送到位后的走位序列，每步包含：
    - `direction`：方向，可选 `up` / `down` / `left` / `right` / `left_up` / `left_down` / `right_up` / `right_down`
    - `drag_time`：拖拽秒数，越久走得越远
    - `pause_time`：停留/战斗秒数（对于非boss需要进行停留战斗的需要进行填写，比如攻击路上的小兵）
- `refresh_enabled`：打完一轮后是否执行换图刷新（`false` 则只循环）
- `refresh`：一轮结束后的刷新动作
  - `map` / `level`：刷新去的图，默认 5-1
  - `return_home`：`false`（默认）=在 5-1 直接点传送按钮开始下一轮；`true`=先回城、确认、再开始下一轮。**只要进入 5-1 就算换图刷新**，所以 `false` 少两次点击、每轮更快
  - `wait_seconds`：到 5-1 后停留的秒数（独立的一个值，不跟随别的参数）
  - `arrive_wait`：到 5-1 后、点回城前的额外等待（默认 0，只有 `return_home: true` 时才有意义）
  - `first_transport_wait`：下一轮第一次传送后的保底等待秒数（角色加载慢就调大）
- `timing`：`after_kill_pause`（打完到回城的间隔）、`after_go_home_pause`（回城后等待）

示例（自定义一条两个 Boss 的路线）：

```json
"我的路线": {
  "bosses": [
    { "name": "2-1", "map": 2, "level": 1,
      "steps": [ { "direction": "right", "drag_time": 1.0, "pause_time": 3.0 } ] },
    { "name": "3-1", "map": 3, "level": 1,
      "steps": [ { "direction": "down", "drag_time": 6.0, "pause_time": 3.0 } ] }
  ],
  "refresh_enabled": true,
  "refresh": { "map": 5, "level": 1, "wait_seconds": 2, "return_home": false },
  "timing": { "after_kill_pause": 1, "after_go_home_pause": 6 }
}
```

## 内置路线

- **默认路线**：后期刷钱路线，依次打 2-1 → 3-1 → 3-2 → 3-3 → 4-1，打完一轮刷新 Boss 再循环，适合战力较高时持续刷金币
- **1-2路线**：7 万战力前的开荒路线（1-2 → 2-1 → 2-2 → 3-1，含 xb 过图条目）。如果你的游戏里还没有某些地图/层数，**直接删除对应条目即可**
