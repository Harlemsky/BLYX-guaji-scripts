# 模板图片目录

把识别用的模板 PNG 放在这里，脚本会在运行中自动加载。当前规划：

| 模板名 | 用途 |
|---|---|
| `transport_menu.png` | 传送菜单打开状态（确认点击成功 / 检测菜单关闭，判定传送触发） |

模板从 `templates_src/` 的整屏截图中裁剪得到。没有模板时脚本自动回退到固定等待。
传送完成判定：无加载画面，采用“菜单关闭 + 窗口画面稳定”（不依赖具体地图画面）。
Boss 战斗结束判定：不依赖血条模板（不同 Boss 血条位置不同、倒地后 UI 不消失），
采用“开战宽限后画面连续稳定约 2.5 秒”判定，对任何 Boss 通用。
